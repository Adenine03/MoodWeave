# MoodWeave

MoodWeave is a music-focused machine learning project for analyzing audio features, mood patterns, and recommendations.

## Project goals
- Explore music datasets and extract audio features
- Build a model to classify or predict mood/emotion
- Visualize patterns in music preferences and audio characteristics
- Prepare a clean workflow for experimentation and iteration

## Structure
- `data/` — dataset files and local data assets
- `src/` — Python source code for preprocessing, modeling, and evaluation
- `notebooks/` — exploratory notebooks and experiments
- `requirements.txt` — Python dependencies

## Quick start
```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
pip install -r requirements.txt
```
